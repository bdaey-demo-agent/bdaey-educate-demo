# منصة بدائي (Bdaey) 📖

منصة إلكترونية متكاملة لتعليم وتحفيظ القرآن الكريم عن بُعد، تهدف إلى ربط الطلاب بمعلمين متخصصين في جلسات فردية مباشرة.

---

## ✨ المميزات

### للطلاب 🎓
- **البحث عن معلم**: تصفح المعلمين وتصفيتهم حسب التخصص والتقييم
- **حجز الجلسات**: اختيار الباقة المناسبة وحجز المواعيد بسهولة
- **جلسات مباشرة**: فيديو تفاعلي مع المعلم عبر Daily.co
- **محفظة إلكترونية**: شحن الرصيد ودفع مقابل الجلسات
- **تقييم المعلمين**: تقييم الجلسات وإضافة مراجعات
- **المتابعة**: تتبع التقدم في الحفظ والمراجعة
- **المكافآت**: نقاط وشارات تحفيزية عند الإنجاز
- **كوبونات خصم**: استخدام أكواد الخصم لشحن المحفظة

### للمعلمين 👨‍🏫
- **الملف الشخصي**: عرض المؤهلات والخبرات والشهادات
- **إدارة الباقات**: إنشاء وتعديل الباقات التعليمية
- **جدول الجلسات**: إدارة المواعيد والجلسات القادمة
- **المحفظة**: متابعة الأرباح وسحب المستحقات
- **التواصل**: محادثة مباشرة مع الطلاب
- **التقارير**: إحصائيات الجلسات والطلاب

### للإدارة 👤
- **لوحة التحكم**: إحصائيات شاملة عن المنصة
- **إدارة المستخدمين**: متابعة الطلاب والمعلمين
- **الطلبات**: الموافقة على طلبات انضمام المعلمين
- **السحوبات**: إدارة طلبات سحب المعلمين
- **الباقات**: الإشراف على الباقات التعليمية
- **الكوبونات**: إنشاء وإدارة أكواد الخصم
- **الإعدادات**: ضبط عمولة المنصة وإعدادات أخرى

## 🛠 التقنيات المستخدمة (ببساطة)

- **الجزء الخلفي (API)**: C# - ASP.NET Core 10 (نظام تشغيل الخادم)
- **الجزء الأمامي (الموقع)**: React + TypeScript (الواجهة اللي تشوفها)
- **قاعدة البيانات**: PostgreSQL (نظام تخزين البيانات)
- **بوابة الدفع**: Kashier (دفع إلكتروني مصري)
- **الفيديو المباشر**: Daily.co (جلسات فيديو تفاعلية)
- **التخزين السحابي**: AWS S3 (لحفظ الصور والملفات)
- **الاستضافة**: Fly.io (لـ API) + Vercel (للموقع)
- **الإشعارات الفورية**: SignalR (لما توصل رسالة بدون ما تحدث الصفحة)
- **المصادقة**: JWT + Google Login (تسجيل الدخول آمن)

## 🚀 كيفية التشغيل (للمطورين)

### المتطلبات الأساسية
1. **.NET 10 SDK** - لتشغيل API
2. **Node.js 20** - لتشغيل الموقع
3. **PostgreSQL** - قاعدة بيانات (أو استخدام Neon.tech السحابي)

### خطوات التشغيل

**تشغيل الخادم الخلفي (API):**
```bash
cd backend
dotnet restore
dotnet run
```
يشتغل على: `http://localhost:5000`

**تشغيل الموقع (Frontend):**
```bash
cd quran-front
npm install
npm run dev
```
يشتغل على: `http://localhost:5173`

## 📁 هيكل المشروع الأساسي

```
backend/          ← كود الخادم الخلفي (API)
  ├── Controllers/    ← نقاط الوصول (الخدمات اللي يستقبلها الخادم)
  ├── Data/           ← قاعدة البيانات (الجداول والعلاقات)
  ├── Migrations/     ← تحديثات قاعدة البيانات
  ├── Services/       ← المنطق الداخلي للتطبيق
  └── Middleware/     ← طبقات الحماية والمرور

quran-front/      ← كود الموقع (الواجهة)
  ├── src/pages/      ← الصفحات (40+ صفحة)
  ├── src/components/ ← المكونات القابلة لإعادة الاستخدام
  ├── src/services/   ← التواصل مع الخادم الخلفي
  └── src/context/    ← إدارة الحالة (التسجيل، الثيم)
```
