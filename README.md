# منصة بدائي (Bdaey)

منصة متكاملة لتحفيظ القرآن الكريم أونلاين — تدير العلاقة بين الطلاب والمعلمين والإدارة بكل احترافية.

---

## المميزات لكل مستخدم

### 👨‍🎓 الطالب

| الصفحة | الوظيفة |
|---|---|
| لوحة التحكم | عرض الرصيد، الحجوزات النشطة، الجلسة القادمة، الإشعارات |
| الجدول | عرض الجلسات القادمة بالتقويم |
| المتجر | تصفح المعلمين، تصفية (تخصص، جنس، السعر، التقييم)، إضافة مفضلة |
| الحجوزات | حجز الباقات، إلغاء الحجز، متابعة حالة الحجز |
| الجلسات | حضور الجلسة المباشرة (Daily.co)، تقييم الجلسة |
| المحفظة | شحن الرصيد (Kashier)، عرض المعاملات |
| التقدم | متابعة التقدم التعليمي |
| لوحة الشرف | نقاط وشارات، ترتيب بين الطلاب |
| الرسائل | محادثة مباشرة مع المعلمين |
| الملف الشخصي | تعديل البيانات الشخصية |

---

### 👨‍🏫 المعلم

| الصفحة | الوظيفة |
|---|---|
| لوحة التحكم | إحصائيات (الرصيد، الدخل اليومي، عدد الطلاب، التقييم، الجلسة القادمة) |
| الباقات | إنشاء وتعديل الباقات (عدد الجلسات، المدة، السعر، أوقات التوفر، الجنس المسموح) |
| الحجوزات | قبول أو رفض حجوزات الطلاب |
| الطلاب | عرض الطلاب المسجلين |
| الجدول | إدارة أوقات الجلسات |
| الجلسات | بدء الجلسة، تسجيل الحضور/الغياب |
| المحفظة | عرض الأرباح، طلب سحب |
| الملف الشخصي | السيرة الذاتية، التخصصات، الشهادات، الإجازات، العينة الصوتية، رفع المستندات (الهوية، المؤهلات) |
| الرسائل | محادثة مباشرة مع الطلاب |

### 🔧 الإدارة (Admin)

| الصفحة | الوظيفة |
|---|---|
| نظرة عامة | إحصائيات المنصة: المستخدمين، المعلمين، الحجوزات، الإيرادات، الجلسات، التقييم، أرصدة المحافظ، الباقات النشطة |
| المعلمون | عرض/بحث، الموافقة على الطلبات، تعديل العمولة، إضافة غرامة حذف الباقة، حظر/إلغاء حظر، عرض المستندات |
| الطلاب | عرض/بحث، حظر/إلغاء حظر |
| المستخدمون | إدارة موحدة — تصفية حسب الدور، حظر، حذف (مع حماية)، إعادة تعيين كلمة السر، انتحال الشخصية |
| الحجوزات | عرض جميع الحجوزات، إلغاء مع استرداد، تصفية |
| الباقات | إدارة الباقات (تفعيل، إيقاف، أرشفة)، إضافة ملاحظات إدارية |
| أكواد الخصم | إنشاء/إدارة (كود، المبلغ، الحد الأقصى، تاريخ الانتهاء) |
| السحوبات | الموافقة/رفض طلبات السحب للمعلمين |
| الإعدادات | العمولة العامة، غرامة حذف الباقة |
| المالية | نظرة عامة على الإيرادات والعمولات |
| دليل الإدارة | دليل استخدام النظام للإداريين |

## تقنية المشروع

| الطبقة | التقنية |
|---|---|
| **الواجهة الأمامية** | React 18, TypeScript, Vite 7, Tailwind CSS 3, React Router 7, React Helmet Async |
| **المكتبات** | Axios, Headless UI, Heroicons, Framer Motion, React Hot Toast, Font Awesome |
| **الفيديو المباشر** | Daily.co (React SDK) |
| **الرسائل الفورية** | SignalR |
| **المصادقة** | JWT, Google SSO |
| **الواجهة الخلفية** | ASP.NET Core 10, C#, Entity Framework Core 10 |
| **قاعدة البيانات** | PostgreSQL (Neon) — schema `quran` |
| **التخزين** | S3-compatible (رفع المستندات والصور) |
| **الدفع** | Kashier (بوابة دفع مصرية) |
| **النشر** | Frontend: Vite (dev) / Fly.io (prod) • Backend: Fly.io |

## التشغيل محلياً

### المتطلبات
- Node.js 18+
- .NET 10 SDK
- PostgreSQL (أو استخدام قاعدة Neon عن بُعد)

### 1. قاعدة البيانات
```bash
# الاتصال تلقائي بقاعدة Neon — لا تحتاج تثبيت PostgreSQL محلياً
```

### 2. Backend
```bash
cd backend
dotnet restore
dotnet run --launch-profile http
# يعمل على http://localhost:5000
```

### 3. Frontend
```bash
cd quran-front
npm install
npm run dev
# يعمل على http://localhost:5173
```

### 4. الدخول
| المستخدم | البريد الإلكتروني | كلمة السر |
|---|---|---|
| **أدمن** | admin@bdaey.com | admin!bdaey123 |

> حساب الأدمن يُزرع تلقائياً عند أول تشغيل في وضع Development.
